# v0.5.9-lite — Terminal and UI Improvements

A follow-up to the October upstream sync, adapting changes from 14 additional upstream source commits. Warp Lite remains a local-first terminal with embedded Warp AI/cloud product surfaces and telemetry disabled.

## Highlights

- **Right-click paste:** optional paste behavior across terminal blocks and inputs; Shift+right-click opens the context menu. Terminal programs that own mouse input retain their events.
- **macOS TIFF clipboard:** recognizes TIFF image data, including the existing local CLI-agent paste path.
- **Editor and UI core:** avoids caching transient editor layouts, retains font fallback requests, and reduces generic update/spawn code. No measured speedup percentage is claimed.
- **Font and RTL reliability:** fixes missing-glyph-bounds handling and reversed RTL smart-selection indices; updates the non-CoreText font fallback dependency.
- **Local CLI integrations:** Grok and Kiro command detection/identity and rich-input handling. Grok adds OSC 9/777 notifications and explicit user-triggered hook installation. Local pluggable notifications are enabled in the default build; command detection no longer assumes the notification plugin is installed.
- **Windows source adaptations:** backdrop choices and legacy Acrylic preference migration, plus WGPU recovery after device loss. Windows binaries are not distributed or runtime-tested in this release.
- **Local diagnostics:** full error-chain keybinding logs and once-per-run flex diagnostics without restoring telemetry.

These are selective adaptations, not 14 complete cherry-picks. [Source inventory and implementation report](https://github.com/terzigolu/warp-lite/blob/v0.5.9-lite/WARP_LITE_SYNC_FOLLOWUP_2026-10.md).

## Validation and known limits

- 1,258 selected tests passed; 7 ignored. One application test still fails because it expects Lite's disabled AI context menu. Whole-workspace test success is not claimed.
- Default Cargo check and optimized macOS release build passed. Clippy passed with an explicit exception for the existing disabled AI-panel boolean expression; other warnings remain.
- Native macOS launch, shell command execution, Turkish/wide-character output, and TIFF-only clipboard paste into a synthetic Grok OSC 777/PTY session passed. The paste delivered the expected Ctrl+V byte (`0x16`). Authenticated Grok/Kiro provider requests were not tested.
- Windows/Linux native-runtime validation and full hosted CI success are not claimed.
- **Open dependency work:** upstream's rmcp 2.2 security update (`114bacea6d3041e04970ead8f86c610c563ae865`) is not included. Lite still uses a 0.10 fork and requires a separate transport/API migration; remediation or non-applicability is not claimed.

Detailed [validation record](https://github.com/terzigolu/warp-lite/blob/v0.5.9-lite/docs/upstream-sync/2026-10-03-validation.json) records the tested implementation revision and scope.
